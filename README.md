
# Adversa Technologies — Corporate Website Prototype

A responsive, dependency-free corporate website for Adversa Technologies and the AdversaShield product family.

## Pages

- `index.html` — corporate homepage and platform overview
- `validate.html` — AdversaShield Validate
- `remediate.html` — AdversaShield Remediate
- `complete.html` — AdversaShield Complete
- `finattack.html` — FINATTACK Intelligence
- `company.html` — company positioning, architecture and principles

## Brand architecture used

- **Company:** Adversa Technologies
- **Platform:** AdversaShield
- **Product 1:** AdversaShield Validate
- **Product 2:** AdversaShield Remediate
- **Integrated package:** AdversaShield Complete
- **Intelligence engine:** FINATTACK Intelligence

## Positioning

**Category:** Financial Adversarial Resilience Platform  
**Core message:** From exploitable risk to verified resilience.

The copy intentionally avoids claims such as fully autonomous production deployment, universal remediation, guaranteed compliance or “first in the world.” It presents the current offer as a private pilot / design partner program and keeps human approval before production changes.

## Run locally

Open `index.html` directly in a browser, or run a local server:

```bash
python -m http.server 8080
```

Then visit `http://localhost:8080`.

## Production adaptation checklist

1. Replace prototype contact handling with a secure backend or CRM integration.
2. Confirm the final domain, legal entity name and official email addresses.
3. Add approved privacy, security, legal and responsible-testing pages.
4. Replace conceptual dashboard data with validated product screenshots.
5. Add approved certifications only after they are obtained.
6. Add analytics with consent management appropriate to target jurisdictions.
7. Conduct accessibility, security, performance and legal reviews before launch.
